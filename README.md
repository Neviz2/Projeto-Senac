# Projeto Senac

Este projeto foi desenvolvido para a disciplina do SENAC com o objetivo de praticar o desenvolvimento de aplicações utilizando Java e Spring Boot. O sistema realiza o gerenciamento de clientes, usuários, mercadorias e serviços, permitindo operações de cadastro, consulta, alteração e exclusão de registros.

No desenvolvimento foram utilizados Java, Spring Boot, Spring Data JPA, Hibernate, PostgreSQL, Maven e Lombok. O projeto segue uma estrutura organizada em camadas, separando controllers, services, repositories e models para facilitar a manutenção e o entendimento do código.

As principais funcionalidades do sistema são:

- Cadastro de clientes
- Cadastro de usuários
- Cadastro de mercadorias
- Cadastro de serviços
- Consulta de registros
- Alteração de dados
- Exclusão de registros
- Integração com banco de dados PostgreSQL

Para executar o projeto é necessário ter Java, Maven e PostgreSQL instalados. Após clonar o repositório, basta configurar o banco de dados no arquivo `application.properties` e executar a aplicação.

Este projeto foi desenvolvido com o objetivo de colocar em prática os conhecimentos adquiridos durante o curso, principalmente relacionados à criação de APIs REST, persistência de dados e utilização do framework Spring Boot.
